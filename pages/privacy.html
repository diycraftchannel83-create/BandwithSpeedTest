Bandwidth Speed Test — Wins Mediatama

Aplikasi mengukur kualitas koneksi internet melalui layanan pengujian Cloudflare. Saat pengujian berjalan, alamat IP pengguna diproses oleh Cloudflare. Cloudflare menyatakan bahwa data pengukuran dapat digunakan untuk insight agregat kualitas koneksi internet.

Lokasi dan provider

Fitur lokasi perangkat, jika diaktifkan pada versi aplikasi mendatang, akan meminta izin secara terpisah. Lokasi presisi tidak diperlukan untuk menjalankan pengukuran dasar. Informasi ISP dapat diperkirakan dari IP/ASN dan tidak selalu sama dengan operator SIM.

Penyimpanan

Versi awal tidak membuat akun dan tidak mengirim riwayat pengujian ke server milik pengembang. Riwayat lokal dapat ditambahkan pada versi berikutnya.

Penggunaan data

Satu pengujian dapat menggunakan hingga sekitar 200 MB data menurut informasi Cloudflare. Pengguna harus menyetujui peringatan kuota sebelum pengujian.

Kontak

Untuk pertanyaan privasi, hubungi pengembang Wins Mediatama melalui kanal dukungan resmi yang akan dicantumkan pada halaman aplikasi.

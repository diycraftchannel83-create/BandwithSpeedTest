Bandwidth Speed Test — Wins Mediatama

Kebijakan ini menjelaskan data yang diproses saat Anda menggunakan situs/aplikasi Bandwidth Speed Test.

Pengukuran kecepatan

Pengujian menggunakan pustaka open-source Cloudflare Speed Test dan mengirim permintaan pengukuran ke jaringan Cloudflare. Alamat IP dan telemetri koneksi dapat diproses oleh Cloudflare sesuai kebijakan privasi Cloudflare. Pengujian dapat menggunakan hingga sekitar 200 MB data.

IP, ISP, dan perkiraan lokasi

Halaman meminta informasi IP publik, penyedia jaringan/organisasi, serta perkiraan kota, wilayah, dan negara melalui layanan IPWho.is. Permintaan ini mengungkapkan alamat IP kepada penyedia layanan tersebut. Lokasi ditaksir dari IP dan bukan lokasi GPS. Informasi ISP dapat menunjukkan organisasi pemilik jaringan atau transit, bukan selalu operator SIM.

Riwayat pengujian

Sepuluh hasil terakhir ditampilkan dari penyimpanan lokal browser/perangkat (maksimal 30 catatan disimpan). Data ini tidak dikirim ke server milik Wins Mediatama. Menghapus data situs/aplikasi atau menggunakan fitur Hapus Riwayat akan menghapus catatan lokal.

Jaringan perangkat

Jika didukung browser, aplikasi membaca kategori koneksi dan perkiraan downlink dari Network Information API. Informasi ini bersifat perkiraan dan tidak selalu tersedia.

Izin lokasi

Aplikasi tidak meminta izin GPS atau lokasi presisi. Lokasi yang ditampilkan hanya perkiraan berdasarkan IP.

Kontak

Pengembang: Wins Mediatama. Informasi kontak dukungan akan dicantumkan pada halaman distribusi aplikasi.

Dengan menggunakan fitur informasi jaringan, Anda memahami bahwa permintaan dilakukan kepada penyedia layanan pihak ketiga tersebut.
